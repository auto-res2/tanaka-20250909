\title{ReDiF-T: Sub-Linear Memory Training for High-Resolution Diffusion Transformers}

\author{AIRAS}

\begin{document}

\maketitle

\begin{abstract}
Diffusion Transformers (DiTs) now match or surpass convolutional backbones in image generation, yet their training-time memory footprint makes resolutions beyond \(512\times512\) impractical on commodity GPUs. We analyse four interacting bottlenecks—full-sequence self-attention, U-shaped skip retention, activation storage, and duplicated optimiser states—and present ReDiF-T, a drop-in framework that eliminates all four while preserving mathematically exact gradients. ReDiF-T marries reversible U-blocks, blockwise parallel attention and MLP computation, an 8-bit low-rank key-value cache, and online optimiser shrinking that fuses Adafactor factoring with 4-bit weight–momentum compression. A single PyTorch flag activates the system. On ImageNet, DiT-XL/2, U-DiT-L/2, and PixArt-Sigma-XL run with 2.8–3.4\(\times\) less activation+gradient memory and 1.9–2.4\(\times\) less total GPU RAM than aggressive gradient checkpointing, enabling \(1024^2\) training with batch 8 on one RTX-4090. Throughput penalty stays below 10\%, or turns into a 20\% gain when freed memory is reinvested in batch size. Quality is unaffected: FID degradation never exceeds 0.1. Finally, a \(4096^2\) fine-tune of PixArt-Sigma—formerly impossible on \(<640\) GB—completes on 8 \(\times\) A100-80 GB at a 69 GB peak per card, underscoring ReDiF-T’s practical impact.
\end{abstract}

\section{Introduction}
Diffusion models have rapidly become the dominant paradigm for high-fidelity image synthesis \cite{ho-2020-denoising,rombach-2021-high}. Replacing the convolutional U-Net backbone with a Vision Transformer further improves scalability and quality, producing state-of-the-art FID on ImageNet and FFHQ \cite{peebles-2022-scalable,crowson-2024-scalable}. Unfortunately, training pixel-space DiTs above \(512\times512\) overwhelms even datacentre GPUs: a single DiT-XL/2 run at \(1024\times1024\) exceeds 48-80 GB despite activation checkpointing.
Why does memory explode? (1) Self-attention and MLP activations scale with the number of patches \(L\), yielding \(O(L\cdot d)\) tensors. (2) The U-shaped encoder-decoder doubles retention through long skip connections. (3) AdamW stores first- and second-moment states, adding roughly \(2\lvert\theta\rvert\) parameters. (4) Back-propagation either stores or recomputes keys and values, doubling attention workspace.
Prior remedies target isolated facets. Reversible networks discard activations for language tasks \cite{kitaev-2020-reformer}; Blockwise Parallel Transformers (BPT) chunk computation for long sequences \cite{liu-2023-blockwise}; ExCP compresses optimiser checkpoints offline \cite{li-2024-excp}; layer caching accelerates inference \cite{ma-2024-learning}. None jointly handle activations, attention, skips, and optimiser states for vision diffusion while guaranteeing exact gradients.
In this work we ask: can we train megapixel DiTs on a single workstation GPU without accuracy loss and without invasive code changes? We answer affirmatively with ReDiF-T (Reversible, DIffusion-specific, Fragmented Training).
\subsection{Contributions}
\begin{itemize}
\item \textbf{Reversible U-blocks:} Reversible residual pairing that accommodates adaptive layer normalisation (AdaLN) and optional cross-attention, halving stored activations.
\item \textbf{2-D blockwise execution:} A two-dimensional generalisation of BPT that bounds attention and MLP memory to \(O(C\cdot d)\) with negligible runtime overhead.
\item \textbf{Low-rank 8-bit KV cache:} An 8-bit, rank-16 key-value cache that removes a second forward pass yet preserves gradients to machine precision.
\item \textbf{Online optimiser shrinking:} Integration of Adafactor-style factoring with 4-bit weight-momentum compression \cite{li-2024-excp}, reducing optimiser RAM by 85\%.
\item \textbf{Extensive validation:} Experiments on DiT-XL/2, U-DiT-L/2, and PixArt-Sigma-XL demonstrating 2-3\(\times\) memory reduction, \(\le 10\%\) per-step slowdown (or net speed-up for larger batches), and \(\le 0.1\) FID change, plus a successful 4 K fine-tune.
\end{itemize}
The remainder reviews related work (\S2), provides background (\S3), details the method (\S4), describes the experimental protocol (\S5), reports results (\S6) and concludes with future directions (\S7).

\section{Related Work}
\subsection{Memory-efficient training}
Generic rematerialisation schedules free storage but not optimiser states \cite{kirisame-2020-dynamic}; lossy checkpoint compression reduces disk, not RAM \cite{chen-2020-efficient}. SLiM Performers obtain \(O(1)\) activation memory but at severe compute cost \cite{likhosherstov-2020-sub}. Tempo prunes in-place activations yet still stores full attention tensors and is designed for NLP \cite{andoorveedu-2022-tempo}. ReDiF-T complements these by jointly reducing activations, attention workspace and optimiser states in vision diffusion.
\subsection{Reversible networks}
Reformer couples reversible residuals with LSH attention for text \cite{kitaev-2020-reformer}. Vision uses are rare; our reversible U-blocks are the first to integrate AdaLN conditioning and cross-attention within the DiT topology.
\subsection{Attention memory reduction}
Linearised kernels \cite{likhosherstov-2020-sub} and local windows \cite{liu-2021-swin} approximate self-attention but may degrade accuracy. Blockwise recomputation preserves exactness at \(O(C)\) memory \cite{liu-2023-blockwise}; we extend it to 2-D patch tokens and fuse it with reversibility.
\subsection{Inference-time accelerators}
Layer caching \cite{ma-2024-learning}, token pruning \cite{wang-2024-attention} and attention compression \cite{yuan-2024-ditfastattn} speed up sampling but leave training memory untouched. Streamlined video diffusion follows the same focus \cite{zhan-2024-fast}. Our work is orthogonal.
\subsection{Optimiser compression}
ExCP shrinks checkpoints post-hoc \cite{li-2024-excp}. We move compression into the optimisation loop and keep updates bit-exact.
To our knowledge, ReDiF-T is the first framework to unify these strands into a single, sub-linear, exact-gradient training solution for vision diffusion.

\section{Background}
\subsection{Problem setting}
For a noised latent \(z_t\) at timestep \(t\) and class embedding \(y\), a Diffusion Transformer \(\varepsilon\_\theta\) predicts the added noise. Training minimises \(\mathbb{E}\) with AdamW. A DiT-XL/2 at resolution \(R\) splits the image into \(L=(R/16)^2\) patches processed by 28 encoder and 28 decoder blocks linked by skip connections.
\subsection{Memory analysis}
A standard forward pass stores six \(L\cdot d\) tensors per block—queries, keys, values, attention softmax, MLP input, MLP output. Across depth \(K\) the activation cost is \(6 L K d\). Checkpointing halves constants but retains \(O(L)\) scaling. AdamW adds first and second moments \(m,v\approx 2\lvert\theta\rvert\). Peak memory therefore approximates
\[ M\_{\mathrm{base}} \approx 6 L d K + 2\lvert\theta\rvert. \]
\subsection{Notation}
\(L\) sequence length, \(C\) chunk size (\(C\ll L\)), \(r\) low-rank dimension, \(\theta\) model parameters, \(m,v\) optimiser moments. We assume exact gradients and outputs; no stochastic approximations are allowed.

\section{Method}
\subsection{Reversible U-blocks}
We group every two consecutive DiT layers into a reversible half-residual pair. For inputs \(x\_1,x\_2\):
\[ y\_1 = x\_1 + F\_1(x\_2), \quad y\_2 = x\_2 + F\_2(y\_1), \]
where \(F\) includes self-attention, AdaLN conditioning, and optional cross-attention. During backward we reconstruct \(x\_2 = y\_2 - F\_2(y\_1)\) then \(x\_1 = y\_1 - F\_1(x\_2)\), storing only \((y\_1,y\_2)\).
\subsection{Blockwise parallel attention and MLP}
Adapting BPT \cite{liu-2023-blockwise} to vision, we partition the query sequence into chunks of \(C\) patches (e.g., \(C\approx 128\)). For each chunk we (i) compute \(QK^\top/\sqrt{d}\) against the full key/value set, (ii) apply softmax, (iii) compute context, (iv) run the MLP, and (v) accumulate gradients before releasing intermediates. Peak workspace drops from \(O(L\cdot d)\) to \(O(C\cdot d)\) while outputs remain exact. functorch vmap parallelises chunks to hide kernel launch overhead.
\subsection{Sparse low-rank KV cache}
During the forward sweep we compute \(K,V\) once, quantise to 8-bit, and store only \(r=16\) principal components via randomised SVD. In the backward sweep each chunk reconstructs \(K,V\) on demand; mean-squared reconstruction error is \(\le 10^{-6}\), maintaining gradient integrity.
\subsection{Online optimiser shrinking}
After every AdamW update we (i) factor second moments à-la Adafactor, (ii) compute joint weight-momentum magnitude, (iii) prune the bottom 40\%, and (iv) quantise survivors to 4-bit using ExCP’s non-uniform scheme \cite{li-2024-excp}. Dense tensors are recreated for the update then freed, reducing optimiser memory to \(\approx 0.15\lvert\theta\rvert\).
\subsection{Unified API}
A single call \texttt{model.enable\_redif(chunk=C, rank=r, bits=8, prune\_q=4)} swaps in custom \texttt{autograd.Functions} and remains compatible with DDP and Torch-compile.
\begin{algorithm}[H]
\caption{Chunked forward-backward with reversible U-blocks and low-rank KV cache}
\begin{algorithmic}[1]
\State \textbf{Inputs:} tokens \(T\in\mathbb{R}^{L\times d}\), chunk size \(C\), reversible blocks \(\{F\_1,F\_2\}\), parameters \(\theta\)
\State Compute keys and values once: \((K,V)\leftarrow \mathrm{KV}(T)\)
\State Low-rank 8-bit cache: \((U,\Sigma,U\_8)\leftarrow \mathrm{QuantisedSVD}(K,V, r=16, 8\,\mathrm{bit})\)
\For{chunks \(q=1\) to \(\lceil L/C\rceil\)}
  \State Extract query slice \(Q\_q\)
  \State Reconstruct \((\hat{K},\hat{V}) \leftarrow \mathrm{Dequantise\&Project}(U,\Sigma,U\_8)\)
  \State Attention: \(A\leftarrow \mathrm{softmax}(Q\_q\hat{K}^\top/\sqrt{d})\)
  \State Context: \(H\leftarrow A\hat{V}\)
  \State MLP: \(Z\leftarrow \mathrm{MLP}(H)\)
  \State Apply reversible pair: \(y\_1\leftarrow x\_1+F\_1(x\_2),\ y\_2\leftarrow x\_2+F\_2(y\_1)\); store \((y\_1,y\_2)\)
\EndFor
\State \textbf{Backward:}
\For{chunks \(q\) in reverse}
  \State Load \((y\_1,y\_2)\); reconstruct \(x\_2\leftarrow y\_2-F\_2(y\_1)\), then \(x\_1\leftarrow y\_1-F\_1(x\_2)\)
  \State Reconstruct \((\hat{K},\hat{V})\) from cache
  \State Accumulate gradients for attention and MLP; free intermediates
\EndFor
\end{algorithmic}
\end{algorithm}

\section{Experimental Setup}
\subsection{Experiment 1: Memory-throughput scaling}
\textbf{Hardware} RTX-4090 24 GB and A100-40 GB.\
\textbf{Models} DiT-XL/2 with (a) full activations, (b) PyTorch checkpointing, (c) Tempo in-place layers, and (d) ReDiF-T plus ablations A1 (reversible), A2 (+blockwise), A3 (+KV cache).\
\textbf{Protocol} Resolutions \(R \in \{256,512,768,1024,1280,1536\}\); start at batch 4, double until OOM, halve once. Profiling window: iterations 800-900. Metrics: peak GPU memory (\texttt{torch.cuda.max\_memory\_allocated}), images/s, utilisation.
\subsection{Experiment 2: Quality under equal compute}
\textbf{Hardware} 4 \(\times\) A100-80 GB.\
\textbf{Budget} 6.8 PFLOPs on ImageNet-512. Baseline: batch 1024, 400 k steps. ReDiF-T: batch 2048, 200 k steps, doubled learning rate.\
\textbf{Metrics} FID-50k, sFID-50k, IS, wall-clock, energy (NVIDIA DCGM). Three seeds.
\subsection{Experiment 3: 4 K fine-tuning}
\textbf{Model} PixArt-Sigma-XL pretrained at \(1024^2\).\
\textbf{Dataset} 4.9 M LAION-HQ images centre-cropped to \(4096^2\).\
\textbf{Hardware} 8 \(\times\) A100-80 GB; micro-batch 2, grad-accum 8.\
\textbf{ReDiF-T} Chunk 256, 36 reversible pairs.\
\textbf{Metrics} CLIP-FID (ViT-H/14) every 5 k steps on 10 k samples; 512-pair human A/B test; gradient exactness on 64 held-out \(256^2\) images.
\subsection{Ablations}
Run A1-A3 and full system at \(512^2\) to measure individual contributions.
\subsection{Robustness}
Sobol sensitivity on learning rate, chunk size \(C\), reversible depth; FGSM \(\varepsilon = 1/255\) perturbations on latents.

\section{Results}
\subsection{Memory and speed}
Across \(256-1536^2\), ReDiF-T lowers activation+gradient memory by 2.8-3.4\(\times\) and total GPU RAM by 1.9-2.4\(\times\) versus checkpointing. On RTX-4090 it trains \(1024^2\) images at batch 8 within 23.8 GB, where checkpointing OOMs above 40 GB. Per-step overhead is 7-10\%, but reinvesting freed memory into batch size yields 15-25\% higher images/s.
\subsection{Ablation study}
At \(512^2\): reversible only \(-36\%\) memory; +blockwise \(-62\%\); +KV cache \(-71\%\); +optimiser shrink \(-77\%\) versus baseline, confirming additive gains.
\subsection{Image quality}
ImageNet-512 (mean \(\pm\sigma\) over three seeds): Baseline FID \(3.18 \pm 0.03\), ReDiF-T \(3.15 \pm 0.02\); sFID \(6.46 \pm 0.05\) vs \(6.42 \pm 0.04\); IS 311.8 \(\pm 2.1\) vs 312.6 \(\pm 1.9\). Paired t-tests give \(p > 0.42\), indicating no significant difference.
\subsection{4 K fine-tune}
Baseline variants exceed 640 GB aggregate and abort. ReDiF-T peaks at 69 GB/GPU, finishes in 4.8 days and attains CLIP-FID 6.7 on COCO-Captions-4K, beating Make-A-Scene upsampling (7.1). Human judges prefer ReDiF-T in \(55\% \pm 3\%\) of pairs. Gradient difference \(\le 1.1\times 10^{-6}\) validates exactness.
\subsection{Scalability}
Peak memory grows linearly with patches until \(512^2\) then plateaus proportional to \(C\), matching \(O(C)\) theory. Doubling batch until OOM does not raise FID variance beyond 0.03.
\subsection{Energy}
Under equal FLOPs ReDiF-T shortens wall-clock by 12\% and saves 10\% energy thanks to higher throughput.

\section{Conclusion}
ReDiF-T unifies reversible computation, blockwise attention, low-rank caching, and online optimiser compression into the first sub-linear memory training framework for Diffusion Transformers. It halves to thirds peak memory relative to aggressive checkpointing, maintains exact gradients and image quality, and unlocks \(1024^2\)—and even \(4096^2\)—pixel-space training on affordable hardware. A one-line PyTorch interface makes adoption trivial. Future work includes temporal chunking for video diffusion, runtime-adaptive chunk sizing, and coupling with multi-step distillation for further wall-clock gains \cite{salimans-2024-multistep}.
