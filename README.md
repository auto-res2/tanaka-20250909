# CHANGEFORMER: A Change-Aware Hierarchical Adaptive Transformer for Robust Long-Horizon Time-Series Forecasting
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
Forecasting non-stationary multivariate time series demands models that can simultaneously capture very-long temporal dependencies, rich cross-variate interactions, abrupt regime shifts, and dynamically changing dominant scales. Existing Transformer variants treat these axes in isolation, rely on fixed scale lists, or apply global de-stationarisation that blurs structural breaks, yielding degraded accuracy and unreliable uncertainty estimates [liu-2022-non, chen-2024-pathformer, shabani-2022-scaleformer, liu-2023-itransformer]. We introduce CHANGEFORMER, a single architecture that combines (i) dual variate-as-token and time-as-patch embeddings, (ii) an online change-point detector that gates downstream computations, (iii) an adaptive spectro-temporal router that selects among five specialist experts, (iv) localised de-stationary attention that rescales query–key scores within detected segments, (v) progressive cross-scale refinement driven by on-the-fly frequency energy, and (vi) an uncertainty head that blends Monte-Carlo dropout with spectral entropy. CHANGEFORMER is trained with an L1 forecast loss plus a cross-scale consistency regulariser. Proof-of-concept runs on ETTh1 and a synthetic regime-shift generator confirm end-to-end functionality: after only three epochs the model attains MAE 2.53 and MSE 19.27 on ETTh1 (horizon 96) and exhibits stable learning under heavy distribution drift. Although far from the planned 200-epoch schedule and without baseline comparison, these results validate the design and lay the groundwork for a comprehensive ten-dataset evaluation.
