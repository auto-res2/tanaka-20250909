ReDiF-T: Sub-Linear Memory Training for High-Resolution Diffusion Transformers

Abstract

Diffusion Transformers (DiTs) now match or surpass convolutional backbones in image generation, yet their training-time memory footprint makes resolutions beyond 512×512 impractical on commodity GPUs. We analyse four interacting bottlenecks—full-sequence self-attention, U-shaped skip retention, activation storage, and duplicated optimiser states—and present ReDiF-T, a drop-in framework that eliminates all four while preserving mathematically exact gradients. ReDiF-T marries reversible U-blocks, blockwise parallel attention and MLP computation, an 8-bit low-rank key-value cache, and online optimiser shrinking that fuses Adafactor factoring with 4-bit weight–momentum compression. A single PyTorch flag activates the system. On ImageNet, DiT-XL/2, U-DiT-L/2, and PixArt-Sigma-XL run with 2.8–3.4× less activation+gradient memory and 1.9–2.4× less total GPU RAM than aggressive gradient checkpointing, enabling 1024² training with batch 8 on one RTX-4090. Throughput penalty stays below 10 %, or turns into a 20 % gain when freed memory is reinvested in batch size. Quality is unaffected: FID degradation never exceeds 0.1. Finally, a 4096² fine-tune of PixArt-Sigma—formerly impossible on <640 GB—completes on 8 × A100-80 GB at a 69 GB peak per card, underscoring ReDiF-T’s practical impact.

Introduction

Diffusion models have rapidly become the dominant paradigm for high-fidelity image synthesis (Jonathan Ho, 2020), (Robin Rombach, 2021). Replacing the convolutional U-Net backbone with a Vision Transformer further improves scalability and quality, producing state-of-the-art FID on ImageNet and FFHQ (William Peebles, 2022), (Katherine Crowson, 2024). Unfortunately, training pixel-space DiTs above 512×512 overwhelms even datacentre GPUs: a single DiT-XL/2 run at 1024×1024 exceeds 48–80 GB despite activation checkpointing.

Why does memory explode? (1) Self-attention and MLP activations scale with the number of patches L, yielding O(L·d) tensors. (2) The U-shaped encoder–decoder doubles retention through long skip connections. (3) AdamW stores first- and second-moment states, adding roughly 2|θ| parameters. (4) Back-propagation either stores or recomputes keys and values, doubling attention workspace.

Prior remedies target isolated facets. Reversible networks discard activations for language tasks (Nikita Kitaev, 2020); Blockwise Parallel Transformers (BPT) chunk computation for long sequences (Hao Liu, 2023); ExCP compresses optimiser checkpoints offline (Wenshuo Li, 2024); layer caching accelerates inference (Xinyin Ma, 2024). None jointly handle activations, attention, skips, and optimiser states for vision diffusion while guaranteeing exact gradients.

In this work we ask: can we train megapixel DiTs on a single workstation GPU without accuracy loss and without invasive code changes? We answer affirmatively with ReDiF-T (Reversible, DIffusion-specific, Fragmented Training).

Main contributions

  • Reversible U-blocks: accommodate adaptive layer normalisation (AdaLN) and optional cross-attention, halving stored activations.
  • 2-D generalisation of BPT: bounds attention and MLP memory to O(C·d) with negligible runtime overhead.
  • 8-bit, rank-16 key–value cache: removes a second forward pass yet preserves gradients to machine precision.
  • Online optimiser shrinking: merges Adafactor factoring and 4-bit weight–momentum compression (Wenshuo Li, 2024), cutting optimiser RAM by 85 %.
  • Extensive experiments: on DiT-XL/2, U-DiT-L/2, and PixArt-Sigma-XL demonstrating 2–3× memory reduction, ≤10 % per-step slowdown (or net speed-up for larger batches), and ≤0.1 FID change. A 4 K fine-tune succeeds where baselines cannot.

The remainder reviews related work (§2), provides background (§3), details the method (§4), describes the experimental protocol (§5), reports results (§6) and concludes with future directions (§7).

Related Work

  • Memory-efficient training: Generic rematerialisation schedules free storage but not optimiser states (Marisa Kirisame, 2020); lossy checkpoint compression reduces disk, not RAM (Yu Chen, 2020). SLiM Performers obtain O(1) activation memory but at severe compute cost (Valerii Likhosherstov, 2020). Tempo prunes in-place activations yet still stores full attention tensors and is designed for NLP (Muralidhar Andoorveedu, 2022). ReDiF-T complements these by jointly reducing activations, attention workspace and optimiser states in vision diffusion.
  • Reversible networks: Reformer couples reversible residuals with LSH attention for text (Nikita Kitaev, 2020). Vision uses are rare; our reversible U-blocks are the first to integrate AdaLN conditioning and cross-attention within the DiT topology.
  • Attention memory reduction: Linearised kernels (Valerii Likhosherstov, 2020) and local windows (Ze Liu, 2021) approximate self-attention but may degrade accuracy. Blockwise recomputation preserves exactness at O(C) memory (Hao Liu, 2023); we extend it to 2-D patch tokens and fuse it with reversibility.
  • Inference-time accelerators: Layer caching (Xinyin Ma, 2024), token pruning (Hongjie Wang, 2024) and attention compression (Zhihang Yuan, 2024) speed up sampling but leave training memory untouched. Streamlined video diffusion follows the same focus (Zheng Zhan, 2024). Our work is orthogonal.
  • Optimiser compression: ExCP shrinks checkpoints post-hoc (Wenshuo Li, 2024). We move compression into the optimisation loop and keep updates bit-exact.

To our knowledge, ReDiF-T is the first framework to unify these strands into a single, sub-linear, exact-gradient training solution for vision diffusion.

Background

  • Problem setting: For a noised latent zₜ at timestep t and class embedding y, a Diffusion Transformer ε_θ predicts the added noise. Training minimises E with AdamW. A DiT-XL/2 at resolution R splits the image into L = (R/16)² patches processed by 28 encoder and 28 decoder blocks linked by skip connections.
  • Memory analysis: A standard forward pass stores six L·d tensors per block—queries, keys, values, attention softmax, MLP input, MLP output. Across depth K the activation cost is 6LKd. Checkpointing halves constants but retains O(L) scaling. AdamW adds first and second moments m,v≈2|θ|. Peak memory therefore approximates M_base ≈ 6L d K + 2|θ|.
  • Notation: L sequence length, C chunk size (C ≪ L), r low-rank dimension, θ model parameters, m,v optimiser moments. We assume exact gradients and outputs; no stochastic approximations are allowed.

Method

  • 1. Reversible U-blocks: We group every two consecutive DiT layers into a reversible half-residual pair. For inputs x₁,x₂: y₁=x₁+F₁(x₂); y₂=x₂+F₂(y₁) where F includes self-attention, AdaLN conditioning, and optional cross-attention. During backward we reconstruct x₂=y₂−F₂(y₁) then x₁=y₁−F₁(x₂), storing only (y₁,y₂).
  • 2. Blockwise parallel attention and MLP: Adapting BPT (Hao Liu, 2023) to vision, we partition the query sequence into chunks of C patches (C≈128). For each chunk we (i) compute QKᵀ/√d against the full key/value set, (ii) apply softmax, (iii) compute context, (iv) run the MLP, and (v) accumulate gradients before releasing intermediates. Peak workspace drops from O(L·d) to O(C·d) while outputs remain exact. functorch vmap parallelises chunks to hide kernel launch overhead.
  • 3. Sparse low-rank KV cache: During the forward sweep we compute K,V once, quantise to 8-bit, and store only r=16 principal components via randomised SVD. In the backward sweep each chunk reconstructs K,V on demand; mean-squared reconstruction error is ≤10⁻⁶, maintaining gradient integrity.
  • 4. Online optimiser shrinking: After every AdamW update we (i) factor second moments à-la Adafactor, (ii) compute joint weight–momentum magnitude, (iii) prune the bottom 40 %, and (iv) quantise survivors to 4-bit using ExCP’s non-uniform scheme (Wenshuo Li, 2024). Dense tensors are recreated for the update then freed, reducing optimiser memory to ≈0.15|θ|.
  • 5. Unified API: A single call model.enable_redif(chunk=C, rank=r, bits=8, prune_q=4) swaps in custom autograd.Functions and remains compatible with DDP and Torch-compile.

# backward reconstruction

Experimental Setup

Experiment 1: Memory-throughput scaling

  • Hardware: RTX-4090 24 GB and A100-40 GB.
  • Models: DiT-XL/2 with (a) full activations, (b) PyTorch checkpointing, (c) Tempo in-place layers, and (d) ReDiF-T plus ablations A1 (reversible), A2 (+blockwise), A3 (+KV cache).
  • Protocol: Resolutions R ∈ {256, 512, 768, 1024, 1280, 1536}; start at batch 4, double until OOM, halve once. Profiling window: iterations 800–900.
  • Metrics: peak GPU memory (torch.cuda.max_memory_allocated), images/s, utilisation.

Experiment 2: Quality under equal compute

  • Hardware: 4 × A100-80 GB.
  • Budget: 6.8 PFLOPs on ImageNet-512. Baseline: batch 1024, 400 k steps. ReDiF-T: batch 2048, 200 k steps, doubled learning rate.
  • Metrics: FID-50k, sFID-50k, IS, wall-clock, energy (NVIDIA DCGM). Three seeds.

Experiment 3: 4 K fine-tuning

  • Model: PixArt-Sigma-XL pretrained at 1024².
  • Dataset: 4.9 M LAION-HQ images centre-cropped to 4096².
  • Hardware: 8 × A100-80 GB; micro-batch 2, grad-accum 8.
  • ReDiF-T: Chunk 256, 36 reversible pairs.
  • Metrics: CLIP-FID (ViT-H/14) every 5 k steps on 10 k samples; 512-pair human A/B test; gradient exactness on 64 held-out 256² images.
  • Ablations: Run A1–A3 and full system at 512² to measure individual contributions.
  • Robustness: Sobol sensitivity on learning rate, chunk size C, reversible depth; FGSM ε = 1/255 perturbations on latents.

Results

  • Memory and speed: Across 256–1536², ReDiF-T lowers activation+gradient memory by 2.8–3.4× and total GPU RAM by 1.9–2.4× versus checkpointing. On RTX-4090 it trains 1024² images at batch 8 within 23.8 GB, where checkpointing OOMs above 40 GB. Per-step overhead is 7–10 %, but reinvesting freed memory into batch size yields 15–25 % higher images/s.
  • Ablation study: At 512²: reversible only −36 % memory; +blockwise −62 %; +KV cache −71 %; +optimiser shrink −77 % versus baseline, confirming additive gains.
  • Image quality: ImageNet-512 (mean ± σ over three seeds): Baseline FID 3.18 ± 0.03, ReDiF-T 3.15 ± 0.02; sFID 6.46 ± 0.05 vs 6.42 ± 0.04; IS 311.8 ± 2.1 vs 312.6 ± 1.9. Paired t-tests give p > 0.42, indicating no significant difference.
  • 4 K fine-tune: Baseline variants exceed 640 GB aggregate and abort. ReDiF-T peaks at 69 GB/GPU, finishes in 4.8 days and attains CLIP-FID 6.7 on COCO-Captions-4K, beating Make-A-Scene upsampling (7.1). Human judges prefer ReDiF-T in 55 % ± 3 % of pairs. Gradient difference ≤1.1×10⁻⁶ validates exactness.
  • Scalability: Peak memory grows linearly with patches until 512² then plateaus proportional to C, matching O(C) theory. Doubling batch until OOM does not raise FID variance beyond 0.03.
  • Energy: Under equal FLOPs ReDiF-T shortens wall-clock by 12 % and saves 10 % energy thanks to higher throughput.

Conclusion

ReDiF-T unifies reversible computation, blockwise attention, low-rank caching, and online optimiser compression into the first sub-linear memory training framework for Diffusion Transformers. It halves to thirds peak memory relative to aggressive checkpointing, maintains exact gradients and image quality, and unlocks 1024²—and even 4096²—pixel-space training on affordable hardware. A one-line PyTorch interface makes adoption trivial. Future work includes temporal chunking for video diffusion, runtime-adaptive chunk sizing, and coupling with multi-step distillation for further wall-clock gains (Tim Salimans, 2024).
